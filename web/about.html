PROJECT CONTRIBUTION

Reports you can trace

XRayGuard connects each report finding to a model score, a reporting threshold, an uncertainty estimate, and a class activation map.

What our team integrated

Our contribution is an auditable workflow for generating structured draft reports from the NIH ChestX-ray14 finding vocabulary. The image model supplies the evidence. A template turns that evidence into sentences, and explicit rules check the wording. The interface lets a reviewer inspect those steps on the same image.

DenseNet, temperature scaling, Monte Carlo dropout and class activation maps are established methods. The comparison below positions our implementation within related work. A claim of first-of-its-kind research would require a systematic literature review.

The analysis pipeline

  1. Image classification

    DenseNet-121 processes a resized frontal image and scores 14 NIH findings. The model starts from ImageNet weights and was fine-tuned on 8,000 selected NIH patients.

  2. Validation-derived reporting thresholds

    Per-finding temperature scaling and thresholds determine whether the report includes a finding and whether its wording is uncertain. A threshold chosen on validation data does not guarantee the same precision on test data.

  3. Prediction variability

    The classifier head uses 30 dropout samples over the same pooled image features. High variation can downgrade a definite statement to a possible finding. This measures one source of model variability.

  4. Visual evidence

    Class activation maps highlight regions influencing each flagged finding. Approximate side and zone descriptions come from those maps. These maps do not segment lesions or measure disease size.

  5. Structured reporting

    The deployed writer uses deterministic templates. Findings below threshold do not become confident negative statements. An image with no reporting flags receives an inconclusive assessment.

  6. Consistency verification

    The rule checker looks for unsupported findings, overconfident statements, contradictions, location mismatches, unmeasured severity, devices, measurements, references to priors, unsupported negatives and omissions. The demonstration lets you introduce an error and inspect its correction.

Three forms of evidence

Wording consistency
Does the text agree with the supplied model evidence? The verifier and its injected-error test address this question.
Label-based predictive performance
Do model findings match the NIH reference labels on held-out patients? AUROC, precision, recall and report-label metrics address this question.
Clinical correctness
Does an expert agree with the image interpretation and report in the intended setting? This project has not completed an independent clinician study.

Scope and responsible interpretation

The system expects a frontal chest X-ray in PNG or JPEG format. It does not verify that an upload is a chest X-ray. Other image types, unsupported views, rotation and image quality can produce misleading outputs.

NIH labels come from report text and can contain errors. The 10,000-patient selection enriches training and validation for rare findings. The 1,000-patient test sample has sparse examples of some findings. The current localisation, external-hospital and LLM comparison experiments remain incomplete.

The application processes uploads in memory without saving an upload history. Downloads and printed reports are research drafts. Clinical use requires further validation and appropriate review.
